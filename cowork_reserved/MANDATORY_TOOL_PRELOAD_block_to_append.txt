

MANDATORY TOOL PRELOAD (turno #1 di ogni sessione Cowork)
Dopo il bootstrap ACK e PRIMA di iniziare qualsiasi task operativo, carica via ToolSearch ESPLICITAMENTE i tool elencati sotto. Sono core operativi per il workflow Windows host + per evitare i limiti del Cowork mount sandbox (truncation write >900B, cache stale, permission denied su .git/index.lock, pnpm symlinks invisibili). Una volta caricati, useli come default per ops filesystem reali / process / git su Windows; usa il bash sandbox solo per logica/calcolo non-stateful.

Tool da precaricare:
- mcp__Windows-MCP__PowerShell (default native shell execution Windows)
- mcp__Desktop_Commander__read_file, write_file, edit_block, list_directory, create_directory, move_file, get_file_info, start_search, start_process, read_process_output, interact_with_process, kill_process, list_processes
- mcp__cowork__request_cowork_directory, mcp__cowork__allow_cowork_file_delete

Esecuzione: chiamata ToolSearch in un singolo turno con query "select:mcp__Windows-MCP__PowerShell,mcp__Desktop_Commander__read_file,mcp__Desktop_Commander__write_file,mcp__Desktop_Commander__edit_block,mcp__Desktop_Commander__list_directory,mcp__Desktop_Commander__start_process,mcp__Desktop_Commander__read_process_output,mcp__Desktop_Commander__interact_with_process,mcp__Desktop_Commander__kill_process,mcp__Desktop_Commander__move_file,mcp__Desktop_Commander__create_directory,mcp__Desktop_Commander__get_file_info,mcp__Desktop_Commander__start_search,mcp__cowork__request_cowork_directory,mcp__cowork__allow_cowork_file_delete".
