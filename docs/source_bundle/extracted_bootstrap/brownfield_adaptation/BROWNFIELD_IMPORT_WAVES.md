# Brownfield Import Waves

## Wave 1 — Low-Risk Reference Catalogues

Import/adapt first:

```text
ESCO occupations
ESCO skills
ESCO occupation-skill links
skill classifications
business processes
process KPIs
job families
job templates
courses
learning paths
```

## Wave 2 — Tenant Operating Model

Import/adapt second:

```text
tenants
tenant industry classifications
tenant org units
tenant jobs
tenant job skills
tenant job KPIs
tenant org charts
```

## Wave 3 — Synthetic Person Evidence

Import only if anonymized or development-safe:

```text
users
employee job assignments
employee skills
employee skill assessments
learning enrollments
employee KPI targets
```

## Wave 4 — Advanced Intelligence

Import/adapt as candidate templates:

```text
career paths
succession candidates
salary bands
bonus plans
merit recommendations
enrichment sources
enrichment lineage
```

## Never Import Without Special Approval

```text
PII
payroll
benefits
bank details
medical certificates
attendance
raw SAP HR tables
RLS policies
runtime sessions
```
