# Position Intelligence Profile

## Purpose

The Position Intelligence Profile is the complete requirement model for a position.

## Contents

```text
position_id
organization_unit
branch_or_site
cost_center
job_role
job_family
job_level
esco_occupation_candidate
required_skills
required_proficiency
learning_paths
kpis
assessment_methods
career_paths
succession_relevance
criticality
economic_weight
compensation_profile
validation_status
```

## Rule

The profile describes what the position requires. It does not describe what a person currently has.

Person evidence is stored separately and compared to the position profile.
