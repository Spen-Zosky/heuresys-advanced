Showcase

Page types

Eight canonical Heuresys page types per bundle docs/12_page_types_to_design.md. Each ships with its own layout grammar; this index helps Product Owner and Development calibrate scope when designing a new module.

back to index

  • Dashboard

    /dashboard, /dashboard/executive

    Cross-module KPI overview with cards, sparklines, recent activity.

  • Module with tabs

    /positions, /positions/:id (Catalogue · Skills · Career)

    Top tabs inside a module surface sibling views without leaving context.

  • Module without tabs

    /visualizations, /brownfield-adaptation

    Single-view module: page renders directly under the sidebar selection.

  • Login

    /login

    Public auth entry. Logo + email + password + submit. No shell.

  • Primary authenticated initial page

    /home

    Post-login landing. Distinct from role-specific dashboards: welcome + quick actions + recent activity.

  • Public landing page

    heuresys.com

    Marketing surface. Hero + features + CTA + footer. Brand-led, no shell.

  • Data table page

    /users, /tenants, /admin/roles, /positions catalogue

    Filterable, sortable, paginated tabular list with row actions.

  • Form page

    /positions/new, /me/skills/self-assessment, /admin/roles/edit

    Single-task editor. Field group + validation + Save/Submit.

Showcase routes are gated by NEXT_PUBLIC_ENABLE_SHOWCASE=1 in production builds. Decisions register: D:\ux-design-shared\governance\DECISION_REGISTER.md. Palette and theme persist in localStorage keys heuresys-palette + heuresys-theme.
