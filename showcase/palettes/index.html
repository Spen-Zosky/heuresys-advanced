No-gradient rule (locked)

Heuresys brand identity v1 forbids any gradient (CSS linear-gradient, radial-gradient, Tailwind bg-gradient-*, SVG linearGradient / radialGradient) regardless of theme, palette or page type. Surfaces are flat; depth comes from elevation tokens (shadows + borders), never from color transitions. Any showcase or production surface violating this rule must be flagged and fixed in a fix(brand): commit.

How to decide

  1. View the 5 cards side-by-side. Surface + Primary action button is the fastest filter — does the brand mood read right?
  2. Verify contrast on the primary CTA against WCAG AA (4.5:1 minimum for text).
  3. Test on the Workforce KPI preview — does the value typography retain authority?
  4. Consider the 4-box accent: do the 4 colors still read as a coherent system at chart scale?
  5. Capture the choice via prompts/DESIGN_DECISION_CAPTURE_PROMPT.md → register update.
Showcase routes are gated by NEXT_PUBLIC_ENABLE_SHOWCASE=1 in production builds. Decisions register: D:\ux-design-shared\governance\DECISION_REGISTER.md. Palette and theme persist in localStorage keys heuresys-palette + heuresys-theme.
