# Assets Directory

This directory contains placeholder SVG assets and asset-governance instructions.

The Development Team must replace placeholders with approved Heuresys assets after showcase review and decision approval.

## Rules

- Use SVG as primary source format.
- Use `currentColor` wherever assets should inherit theme colors.
- Optimize SVGs before production use.
- Keep source/master assets separate from generated production variants.
- Record asset decisions in the asset register.
- Generate favicons/app icons from the approved symbol mark.
