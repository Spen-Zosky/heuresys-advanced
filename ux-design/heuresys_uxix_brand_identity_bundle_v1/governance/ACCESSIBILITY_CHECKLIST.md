# Accessibility Checklist

- [ ] All icon-only controls have accessible labels.
- [ ] All external links have meaningful aria-labels where icon-only.
- [ ] Keyboard can access header controls.
- [ ] Keyboard can access sidebar controls.
- [ ] Keyboard can open/close tree groups.
- [ ] Keyboard can use tabs.
- [ ] Focus ring is visible.
- [ ] Color contrast is acceptable in light mode.
- [ ] Color contrast is acceptable in dark mode.
- [ ] Status meaning is not conveyed only by color.
- [ ] Reduced-motion preferences are respected.
- [ ] Menus and dropdowns use accessible primitives.
- [ ] Forms have labels and validation messages.
- [ ] Breadcrumb is accessible navigation.
