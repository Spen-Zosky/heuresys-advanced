# Showcase Generation Prompt

Create browser-rendered showcase pages for the Heuresys UX/IX system.

Required routes:

```text
/showcase
/showcase/shell
/showcase/header
/showcase/sidebar
/showcase/footer
/showcase/palettes
/showcase/typography
/showcase/icons
/showcase/page-types
/showcase/dashboard-cards
/showcase/forms
/showcase/tables
/showcase/charts
/showcase/landing-page
/showcase/login-page
/showcase/primary-initial-page
```

Each route must show realistic Heuresys examples and clearly label variants.

For each showcase, include:

- Purpose.
- Candidate variants.
- Current accepted decision, if any.
- Notes for Product Owner review.
- Screenshot-ready layout.

Do not use empty placeholder boxes. Use realistic HRMS/BPM content, such as positions, skills, KPIs, organization units, learning paths, critical role coverage and workforce intelligence.
