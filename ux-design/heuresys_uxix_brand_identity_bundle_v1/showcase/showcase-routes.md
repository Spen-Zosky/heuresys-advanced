## Route examples

### `/showcase/shell`

Show:

- Expanded sidebar.
- Collapsed sidebar.
- Long sidebar scroll.
- Long content scroll.
- Header/footer persistent behavior.

### `/showcase/header`

Show:

- Required header composition.
- Menu open state.
- Language switch state.
- Palette switch state.
- Theme switch state.
- User menu/logout state.

### `/showcase/icons`

Show:

- Outline library.
- Neutral icons.
- Semantic status colors.
- Navigation icon usage.
- Status icon usage.
